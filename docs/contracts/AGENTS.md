# 接口契约文档

- 以[项目书](../source/PaperTrace_Project_Book_ZH.md)为业务依据，以[技术书](../source/PaperTrace_Technical_Book_ZH.md)为协议参考。已有定义直接引用，避免重复。
- 按层拆分：`README.md` 只做页面 → 方法 → 状态索引；`protocol.md` 集中定义共用规则、类型、任务方法和通用错误；每条业务主线一个文件（如 `discover-read-locate.md`），只写本线方法、类型、错误和样例，共用部分链接 `protocol.md`。
- 新主线随对应功能分支补契约，并在 `README.md` 中更新状态。修改共用协议单独提交，不夹在主线变更中。
- 共用规则包括主题、会话、论文版本和证据锚点的标识，以及任务事件、错误和用户采纳状态。任务完成、证据判断和用户采纳分别记录。
- 每个接口写清用途、请求、响应和失败行为。异步操作补充任务标识、事件顺序和结束状态。主线使用同一篇论文串起请求、响应和事件样例，覆盖成功及关键异常。
- 尚未达成共识的内容标为「待确认」。联调前检查字段名、标识及事件能否在同一组样例中前后对应。
