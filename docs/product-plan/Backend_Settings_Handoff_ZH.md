## 联调步骤

1. 在发现页用公开研究查询检索，检查确认弹窗里的查询词和目的地，再选一条候选加入主题。切换年份或会议也应保留对已排除条目的记录。按错误状态区分没有候选与上游失败。
2. 用 DOI 和 arXiv 各预览一条书目。首次确认入库后应显示「待补 PDF」。重复确认应返回相同论文。上传附件后新旧材料应在同一论文下。修改标题、作者或其他字段，再次匹配时保留手动填写的值。
3. 在会话中保存页码、缩放和页内位置，退出后重新打开。替换 PDF 版本后，旧版本仍可读回之前的位置。已有段落书签继续跳转。
4. 在设置页改模型、保存、重开并测试。按照 [桌面启动说明](../../backend/README.md) 配置文本模型与 OpenAlex。OpenAlex 可尝试无密钥基础调用，团队联调建议用自己的密钥。

## 验证状态与后续

后端测试覆盖候选去重、会议约束、取消后的迟到结果、限流、书目确认、版本冲突和续读持久化。已验证 Crossref 和 arXiv 的公开书目查询，并用 ALCE 的公开 PDF 验证 DOI 入库、补附件、重复导入和页码恢复。当前环境的 OpenAlex 无密钥请求收到限流，成功响应和选入链路用固定响应验证。前端桌面请求适配器与 Python 联调通过。桌面窗口和 Windows 客户端留待走查。

后续优先接稿件句子引用建议；再做 Zotero 迁移、引用内链和导出预览。SCIE／SSCI 收录、JCR 分区和 CCF 等级依赖各自数据来源及使用权限。运行时精简和竞品功能研究见[技术路线](Agentero_Parity_and_Settings_ZH.md)。
