# PaperTrace 前端并行开发交接

基线为联调分支 `papertrace/backend-integration` 的 `3c58365`。该提交合并了上游简体中文和语言选择器，保留了真实多论文工作台。使用 [桌面 RPC 启动方式](../../backend/README.md)联调。浏览器样例可用于验证界面状态，交付验收在真实桌面模式完成。

## 本轮用户故事

学生第一次打开 PaperTrace，从首页拖入一组论文，直接进入主题。她在左边提问，右边阅读 PDF。看到有用的一句，点出处就能定位，核对后把观点存进 Wiki。写作时，她能把选定观点、原文出处和书目一起带到现有编辑器。第二天回到主题，可以继续上次的阅读或复核。

## 并行任务与联调边界

| 优先级与负责人 | 前端先做 | 可直接接入 | 等待后端或共同确认 |
| --- | --- | --- | --- |
| **P0 · 前端 · 统一导入** | 首页、Library、主题三处共用一个导入流程。首页可选已有主题，也可创建主题。批量显示每个文件的结果，重复导入提示已在库中，无法提取文字的论文也有明确状态。 | 复用 `library.import_pdf`、`library.list`、`library.catalog`。以当前主题页真实实现为参考。 | Zotero 先做选一个收藏夹导入当前主题。收藏夹、书目元数据、附件和旧批注的映射由后端处理，先用界面样例对齐预览、失败详情和重试交互。 |
| **P0 · 前端 · 阅读和证据** | 把证据预览变成常驻阅读区。先做翻页、缩放、回到证据页、保存位置，以及从已有提取段落发起提问。选中证据时保留论文标题、版本和页码。 | `evidence.open` → `source.page` 可打开原 PDF 页，`source.read` 可返回提取段落，`reader.position/bookmark` 可读写段落位置。 | 原 PDF 文字层、高亮矩形和 PDF 上的划选需要真实坐标或文字层。没有坐标时只展示页码与摘录；坐标不可用时仍能翻页和读段落。 |
| **P0 · 前端 · 核查后导出** | 提纲继续按观点组织。用户能展开正文依据、实验条件和缺口，勾选要存入 Wiki 或导出的条目。导出预览让用户看到标题、论点、证据、页码和书目。 | `synthesis.list/wiki/review` 支持读回提纲、查看 Wiki、逐项采纳和修订冲突提示。按现有 `anchor_id` 复用读者。 | Markdown 与 BibTeX 的生成、引用键和桌面文件保存由后端负责。现有 `export.create` 是设计契约，真实分支的提纲导出输入仍需两侧确认。 |
| **P0 · 前后端 · 首次打开** | 首次提示只保留“导入论文”和“连接模型”两个动作。模型不可用时，本地导入、阅读和保存仍可用。沿用现有中英文切换，补齐综合工作台新增文案。 | `services.get` 现可读到已配置状态，已有中英文词表和语言选择器。 | 模型凭证的安全保存、连接测试和桌面依赖打包由宿主负责。前端接接口前提供真实缺失状态，不显示已连接。 |
| **P1 · 前后端 · 继续研究和补论文** | 在主题入口呈现上次读到的位置、最近提纲及待查或待复核观点。用户能从一个缺口发起查找，自己挑选结果入库。 | 已有主题、会话、阅读书签及 `needs_review` 数据，可先做恢复界面。 | 真实发现、DOI／arXiv 入库及引用追踪继续由后端提供。在真实模式中明确当前发现结果的来源。 |

前三项可并行。建议先用一个主题串起导入、原文与提纲页面，同时让另一位同学做导出预览。后端优先与前端对齐引用键、证据定位和本地文件保存。整库实时同步、完整 LaTeX 编辑器和订阅广场排在这轮之后。

## 统一交互规则

- 默认从用户正在做的事进入。左边是问题与观点，右边是原文。论文关系、实验对照和审阅差异在点击后展开。
- 显示清楚三个状态。任务是否结束、证据是否支持某条论点、用户是否采纳。部分结果可继续查看，缺失依据和冲突原文留在对应观点下。
- 应用范围按主题、论文版本与锚点校验。论文换版只提示相关 Wiki 条目复核，旧出处仍能打开。并发审阅遇到 `STALE_REVISION` 时刷新预览并让用户重新确认。
- 双语沿用现有词表。可操作标签、状态与错误提供中英文，论文原文及用户输入按原语言显示。

## 联调验收

1. **首次使用**。新建主题，从首页导入两篇真实 PDF，再从 Library 重复导入一篇。只有一个论文条目，主题选中状态正确。混入一本无文字层的 PDF，失败或仅元数据的状态能逐个查看。
2. **原文定位**。用 ALCE、ASQA 和另外四篇同主题论文。生成带证据的相关工作提纲，点击出处打开预期版本和页码。页级模式展示原文摘录，有坐标后再验收页内高亮。实验条件不齐时，界面显示边界。
3. **带走成果**。采纳一条有据观点，导出预览中可检查论点、文献、页码和引用键；接通保存接口后，Markdown 页和 BibTeX 的引用键能对应。用户取消保存时显示取消。
4. **继续研究**。关闭重开后，从同一主题返回提纲和原文；只换一篇论文时，相关 Wiki 条目标记待复核，其他条目或历史出处可正常打开。
5. **竞品试跑**。用同一批论文和同一个问题，记录十分钟内可导出的合格论点数、误判支持次数，以及重开后找回一条待查论点的耗时。合格论点需要人工核对措辞、原文、页码和适用条件。记录固定样例、回环和真实模型各自的运行方式。
