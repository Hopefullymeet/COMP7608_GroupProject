# PaperTrace 竞品功能对齐与技术路线

更新于 2026-11-22。Agentero v0.17.0 是主要对标，验收围绕文献入库、阅读批注、证据整理、写作引用与换版复核。DeepTutor 等产品用于参考有交叉的科研场景。每项需求按 PaperTrace 用户的工作流程取舍，团队独立实现。 [Agentero 官网](https://agentero.app/) · [官方文档索引](https://docs.agentero.app/) · [v0.17.0 发行说明](https://github.com/poco-ai/agentero/releases/tag/v0.17.0)

- 多文档研究需要逐条回到原文。证据矩阵区分作者结论、模型推断和缺失材料。继续追查分歧时，沿用当前主题与已确认的论文版本。 [DeepTutor 学术研究流程](https://raw.githubusercontent.com/HKUDS/DeepTutor/main/docs-for-dev/SCIENTIFIC_RESEARCH.md)

## 2. 模型适配与运行时精简

PaperTrace 使用独立的执行进程，按任务提供查论文引用、搜全文、读片段和查主题 Wiki 四类只读工具。论文、批注、任务状态和证据保存在 SQLite。运行配置的本机对照未测到资源下降，下一步以安装体积、依赖和功能回归作为精简验收依据。

1. **保留引擎**。留模型适配、Agent 循环、工具调度、权限、流式事件、取消、错误回传和运行所需的最小会话组件。记录已加载插件和对模型公布的工具。
2. **裁发行包**。从独立的 PaperTrace 启动组合排除运行时附带的 Web/桌面壳、市场、终端、SSH、通用工作区和通用托管设置。在锁文件、运行依赖、构建与事件路径都验证后，才考虑从派生源码分批删除。外接 ACP 与 MCP 走独立适配器，可选配置，不拖进默认运行组合。
3. **先接公开文献发现**。通过 OpenAlex 做主题候选、DOI 对齐和书目引用线索。外部引用记录供导航，支持程度由本地 PDF 核查。缓存书目请求结果，检索服务不可用时继续读已入库论文。 [OpenAlex Works 与引用](https://help.openalex.org/data/works/citations/)
4. **用可选解析器改善证据**。保留 PDF.js、现有快速提取、OCR/复杂版面按需处理。已有 GROBID 可做书目线索，新增实验先对照 MinerU 或 RAG-Anything 的解析能力。将有效结果统一写为论文版本、页码、区域与来源，继续使用现有 SQLite/FTS5 和 Wiki。只有漏检实验显示需要时，再加入语义重排或向量索引，并比较增加的安装体积和时间。 [SQLite FTS5](https://www.sqlite.org/fts5.html) · [MinerU](https://opendatalab.github.io/MinerU/) · [HKUDS RAG-Anything](https://github.com/HKUDS/RAG-Anything) · [ACP](https://agentclientprotocol.com/get-started/introduction)
5. **验收后才替换默认组合**。同一批公开 PDF、同一固定测试服务，跑工具调用、流式输出、取消、异常重试、重启读回、越出已选范围时拒绝、图文证据定位。比较安装体积、运行依赖数、冷启动、峰值内存和首次增量耗时。功能有回归或资源收益不足时，原运行组合继续作为回退路径。

## 3. 怎样证明 PaperTrace 做得更好

完整体验用同一组公开论文跑一次，从批量导入、找依据、对照论文、保存论点到核查稿件，记录完成时间与中断点。基础操作以任务成功率、点击次数和错误后是否找得到下一步来评估。

| 要验证的能力 | 用户看见的结果 | 对照验收 |
| --- | --- | --- |
| 看懂论文之间的关系 | 区分「引用了」「使用了基准」「结果可直接比较」「只支持这句话的一部分」，标出依据与实验条件 | 用 ALCE/ASQA 验证基准使用，RARR/Self-RAG 验证方法比较。人工核查关系、实验条件和过度归因。 |
| 写作时找到可靠的引用 | 一句话拆到可核查的论点，每篇论文各自对应贡献、适用条件、原文页及区域 | 用同一模型、论文和检索预算比较固定检索、Agent 补查、带已审阅 Wiki 的 Agent。记录正确证据覆盖和误判为充分支持的比例。 |
| 研究积累可以继续用 | 新会话找回已审阅观点，仍能点回论文。来源换版后能指出受影响的观点并提示复核 | 保存一条观点，重启复用，更换一个版本后核对受影响项。记录回查用时、重定位正确率和无关条目是否受到影响。 |
| 用模糊描述找图 | 中文或英文描述能找回实际图块，用户点结果跳回原页 | 在人工标注的图、表、公式和易混淆样例中比较首位命中率、前五命中率、区域定位与缺证时的反馈。 |

功能对齐可从官方说明逐项核对。比较结果需要同任务实测，当前文档中的优先级和组件取舍属于拟议开发安排。
