# PaperTrace 测试基线

本基线以[主仓库的接口索引][index]为范围，以[项目书第 10 节](source/PaperTrace_Project_Book_ZH.md#10-数据与评估)为质量评估依据。下表记录约定行为。真实模型、桌面工作进程和客户端回放分别计分。执行记录见[论文评估报告](paper-evaluation.md)。

## 功能范围

| 用户任务 | 接口依据 | 验收重点 |
|---|---|---|
| 建立主题、会话；检索、细化检索、处置候选 | [发现主线][discover] | 能读回主题、会话、检索步骤及候选当前状态。加入同一论文后主题内只有一条关联。 |
| 导入与整理资料、复核重复项、归档与恢复 | [资料库][library] | 身份冲突进入人工复核；移出主题只删除所选关联；回收前影响发生变化时报 `STALE_REVISION`。 |
| 阅读、问答、点击出处、继续阅读与保存笔记 | [摘要问答][discover]、[全文阅读][library] | 摘要与全文的阅读范围可辨；读回书签时对应所选版本；笔记修订保留旧内容与出处。 |
| 比较论文、维护 Evidence Wiki | [比较与 Wiki][wiki] | 有证据的比较单元格带出处，不可比时说明原因。Wiki 草稿经审阅后才进入正式页，接受部分改动时只应用所选项。 |
| 导入稿件、建议引用、独立回查、审阅与导出 | [稿件与导出][citation] | 回查限定被引或指定来源；一句中所有子论述均获支持才显示 Supported。接受审阅意见与写回稿件分别验证；采纳措辞生成新版本，保留原件。取消导出返回 `saved=false`。 |
| 配置服务、授权材料、持续检索、备份恢复 | [工作区][services] | 凭据接口只返回配置状态；撤销授权后停止后续派发和迟到结果提交；监测间隔为 0 时停用；恢复校验失败时保留原工作区。 |
| 跨页面的任务授权、重试、取消与读回 | [共用协议][protocol]、[工作区][services] | 写入重试不重复产生记录；重连可按事件序号续订；任务历史可读回。恢复检查点前重新核对版本、预算和授权。 |

## 验收用例总表

以下用例使用[发现、阅读与定位契约第 2 节的固定样例][discover]。目标论文为 PubMedQA（DOI `10.18653/v1/D19-1259`）。样例摘要给出两个事实：它是生物医学问答数据集，问题的上下文是对应论文去掉结论后的摘要。摘要没有给出标注预算或完整标注流程。

每条用例从独立工作区或等价的初始数据开始。文中的“该论文”“该版本”“本次任务”均指本次运行取得的 ID。发起问答时，先调用 `task.prepare`，确认发送范围后用返回的确认单调用 `task.start`。结果通过 `task.get` 或终态事件查看；检查“已保存”时，还要用原主题和会话调用 `session.get`，按本次 `task_id` 核对历史。

DISC-01 至 TASK-01 使用当前检出的客户端 mock。UI-01 挂载实际语言组件；后端场景在临时工作区运行。WS-01 至 WS-03 对应前端工作区回归，DATA-01 至 DATA-03 使用合并到主仓库的论文集。

| 用例 ID | 场景 | 前置条件 | 操作与输入 | 预期结果（通过条件） |
|---|---|---|---|---|
| DISC-01 | 检索并重新打开结果 | 新主题“科学问答数据集”及空会话；固定样例首轮未命中，补搜可找到 PubMedQA。 | ① 输入“哪些科学问答数据集使用论文摘要？”，年份选 2019–2022（含边界），查看确认单。<br>② 确认并启动，记录任务 ID 和结果的检索 ID。<br>③ 重新打开最近检索，依次读取 `discovery.latest`、`discovery.get` 和 `discovery.steps`。 | ① 确认单标明搜索和模型两个端点、各自用途及发送的数据类别。<br>② 任务为 `completed`；可见候选中有指定 DOI 的 PubMedQA，状态为 `pending`。<br>③ 最近检索 ID 与步骤②一致，重新打开后仍有该候选。固定样例步骤依次为搜索、决定补搜、再次搜索、停止。 |
| LIB-01 | 重复加入同一候选 | 空主题中已有状态为 `pending` 的 PubMedQA 候选；两次操作使用同一主题、同一轮检索和相同摘要。 | ① 对候选执行 Add，记下论文 ID 和版本 ID。<br>② 用新的 `operation_id` 再执行一次 Add，模拟用户第二次点击。<br>③ 用 `library.list(topic_id)` 读取主题库，用 `discovery.get` 读取候选当前状态。 | ① 首次返回 `decision=added`、`link_status=linked`。<br>② 第二次返回 `already_linked`，论文 ID 和版本 ID 均与首次相同。<br>③ 主题库中目标论文只有一条记录，该主题关联和该版本各出现一次；候选显示为 `added`。 |
| ASK-01 | 摘要有答案 | PubMedQA 已加入主题；会话只选该论文的摘要版本。 | ① 以 `requested_scope=abstract` 提问“PubMedQA 提供给模型的上下文是什么？”。<br>② 读回历史回答，用其 `message_id` 和支持该结论的锚点调用 `evidence.locate`。 | ① 终态为 `completed`，历史中能找到本次回答；`read_sources` 对应所选版本，阅读范围为 `abstract`。<br>② 答案同时表达“对应论文的摘要”和“去掉结论”，允许同义措辞。该句标为 `supported`，至少有一个锚点；定位返回的目标段落包含引句，人工核对原文支持上述两个要点。 |
| ASK-02 | 摘要缺少所问信息 | 空会话只选 PubMedQA 摘要；事先核对摘要未说明标注预算或金额。 | 以 `requested_scope=abstract` 提问“这项研究的标注预算是多少？”。任务结束后，读回正式回答，检查预算相关句子的判断和锚点。 | 成功读取摘要后，任务可按 `completed` 结束。回答说明无法从摘要确定预算；该句为 `evidence_not_established`，且 `anchor_ids=[]`。给出具体金额或引用无关段落作为预算证据，均判失败。 |
| ASK-03（A） | 要求全文，摘要可提供部分答案 | 库中只有 PubMedQA 摘要，无可读全文。摘要写明问答所用的上下文。 | 以 `requested_scope=full_text` 提问“PubMedQA 提供什么上下文？”。任务结束后检查终态、实际阅读范围，并按任务 ID 查询会话历史。 | `status=partial`，`issue.reason=FULL_TEXT_REQUIRED`。实际阅读范围是所选版本的 `abstract`；会话历史中能读回部分回答，内容包含“去掉结论后的摘要”。 |
| ASK-03（B） | 要求全文，摘要无法回答 | 库中只有同一 PubMedQA 摘要，无可读全文，摘要未说明标注预算。 | 独立启动问答，以 `requested_scope=full_text` 提问“标注预算是多少？”。按本次任务 ID 检查终态、错误详情及会话历史。 | `status=failed`，`issue.reason=FULL_TEXT_REQUIRED`。`issue.details.read_sources` 报告已读版本及范围 `abstract`；会话历史中没有本次任务的正式回答。 |
| LOC-01 | 移出主题后打开历史出处 | 已准备一条符合 ASK-01 的历史回答；记下其主题、回答、锚点及实际阅读版本 ID。原始材料和会话历史均保留。 | ① 点击历史出处，记录 `evidence.locate` 返回的论文、版本、段落 ID 和引句。<br>② 将论文移出当前主题，通过 `library.list(topic_id)` 确认该主题已无此论文。<br>③ 重开原会话，再次点击同一回答的同一出处。 | ① 版本等于回答实际读取的版本，目标段落存在且包含非空引句。<br>③ 两次打开的论文、版本、段落 ID 和引句一致。桌面联调时，阅读器应跳到该段落；只打开论文首页判失败。 |
| TASK-01 | 取消后收到迟到结果 | 选择摘要可回答的问题，记录会话已有问答；测试环境可暂缓正式提交并在取消后放行剩余事件。 | ① 启动问答并订阅事件；收到第一条非空 `answer.delta` 后，在提交前调用 `task.cancel`。<br>② 确认取消成功后放行剩余事件，待处理完毕，读取 `task.get` 和 `session.get`。 | ① 取消响应为 `cancelled`。若正式提交先发生，本次未满足测试前提，需重新执行。<br>② 最终任务仍为 `cancelled`。原有问答仍可读回；会话中没有以本次任务 ID 保存的预览或迟到回答。 |
| UI-01 | [中英文切换][lang] | 浏览器允许本地存储；清空语言偏好并使用英文系统区域。 | 打开应用，切换为简体中文并刷新，再切回英文。 | 首次选中“跟随系统”，页面为英文；切换后已翻译控件显示中文，页面语言为 `zh-CN`，刷新后仍为中文；切回后页面语言为 `en`。 |
| CIT-01 | [引用变更后的局部回查][cit] | 稿件已有两条受同一来源换版影响的句子和旧报告。 | 更换来源版本，尝试采纳旧判断；只选择其中一句按新版重查，再读稿本和历史报告。 | 旧证据不能直接采纳；重查使用新版。成功检查的句子退出待重查清单，另一句仍在清单中，旧报告保留复核标记。 |
| LIB-02 | [论文别名持久化][alias] | 记录已入库论文的 ID 和原始题名。 | 设置一个不同于题名的显示别名，重启同一工作区并读回论文。 | 同一论文的别名仍可读回，原始题名与设置前一致。 |
| READ-01 | [图表定位精度][reader] | PDF 的页面文字提到某图，但解析结果没有相应图对象。 | 检索该图并检查返回页码及定位矩形。 | 命中指向含提及文字的页面，矩形为空。将文字命中显示成已定位的图对象判失败。 |
| READ-02 | [PDF 内嵌批注][reader] | 准备含批注和旋转页的 PDF，保存导入前文件字节。 | 读回原生批注，按批注位置打开页面，比较操作前后的原文件。 | 批注仍对应正确页及旋转后的坐标，输入 PDF 字节完全一致。 |
| TR-01 | [选择翻译与断点重试][reader] | 准备选区内外均有文字的页面，以及第二页首次翻译失败的受控服务。 | 确认选区翻译并记录服务输入；用相同设置重开。另对两页发起翻译，第二页失败后重试。 | 选区请求只发送选中文字，目标语言与术语表匹配确认内容；相同选区命中缓存时无外发。两页任务首次为 `partial` 并指出失败页；重试复用第一页结果，补译第二页。 |
| IMP-01 | [书目预览与选择导入][lit] | 使用含重复记录的 RIS 或 CSL JSON，记录导入前资料库。 | 离线预览，检查重复项，选择部分条目提交；以相同操作键重放提交。 | 预览显示候选和重复信息；只有选中项被提交，重放不产生第二份论文。 |
| IMP-02 | [Zotero RDF 迁移][lit] | 准备含集合、笔记及可读取 PDF 附件的 RDF 样例。 | 导入后在资料库查找论文、核对集合归属，打开关联笔记和附件。 | 论文与集合关联、笔记内容及 PDF 附件可对应回输入记录。 |
| CFG-01 | [服务设置持久化][svc] | 读取已有模型配置及修订号，使用测试模型名。 | 保存修改，按同一操作键重发，再读取服务配置。 | 修改得到新修订号；重发返回同一次保存结果，读回模型名一致，模型配置不含明文密钥。 |
| META-01 | [期刊排名目录替换][rank] | 已安装可查询的排名目录，记录已知 ISSN 的查询结果。 | 使用不可接受的自定义目录尝试替换，再查询同一 ISSN。 | 替换失败，原目录仍可查询；结果及目录版本保留，不出现部分替换。 |
| CMP-01 | 比较表修订 | 两篇已导入的样例 PDF，比较 Benchmark 与 Data split。 | 运行比较，修改第一个单元格，再读取版本历史。 | 四个单元格都有锚点，修改只改变目标单元格，旧表保留一版。 |
| CMP-02 | 比较输出截断后恢复 | 已读版本 A 的段落；请求同时比较 A、B 的 method。 | 令首轮响应截断，恢复响应将 A 的同一引句同时用于 A 和 B。 | 执行一次恢复；A 的单元格保留，B 的跨版本引用被过滤。 |
| WIKI-01 | 采纳证据及换版复核 | 两篇样例 PDF 和各自可定位的段落。 | 生成提纲，采纳一项，使用过期修订号重试；替换版本，再读 Wiki。 | 已采纳项保留来源；过期保存返回 STALE_REVISION；换版后旧结论标为待复核。 |
| REV-01 | 独立证据复核 | 初始结论范围过宽，原文只说明测试了两个样本。 | 复核端要求缩小结论；分别返回原文引句和无法定位的引句。 | 可定位的改写保留引用；伪造引句无引用，不能进入 Wiki。 |
| CFG-02 | 模型和复核凭据独立绑定 | 临时凭据目录和内存凭据库，主模型已绑定旧条目。 | 新增凭据，先只绑定复核端，再切换主模型并删除新条目。 | 两个绑定独立；删除后两端不再引用该条目；返回值不包含明文密钥。 |
| AGT-01 | 工具请求被截断 | 已提供已读段落，模型返回不完整的工具调用。 | 模拟长度截断，随后返回报告证据不足的有效回答。 | 工具执行次数为零；恢复后的回答保留空证据列表。 |
| WS-01 | 备份恢复 | 在本地 mock 建立带书签的工作区，保存备份。 | 恢复可用备份，再试损坏版本，并读回工作区。 | 首次恢复原工作区，损坏版本被拒绝，已有记录仍可读取。 |
| WS-02 | 授权与恢复 | 已生成确认单；另准备触发预算限制的任务。 | 修改服务配置后使用旧确认单，随后按原范围恢复受限任务。 | 旧确认失效；恢复只执行一次，沿用原范围。 |
| WS-03 | 桌面 RPC 适配 | 在受控桌面通道建立任务订阅，提供服务端错误。 | 发起调用、接收错误，再取消事件订阅。 | 请求带 JSON-RPC ID；错误可读；取消订阅后解绑通道。 |
| DATA-01 | 数据完整性 | 使用同次检出的 manifest、PDF、逐页文本与评审文件。 | 重算 SHA-256，逐条按页、字符偏移和版本检查引句，核对输入与评分记录 ID。 | 文件与摘要一致，每个引句精确匹配，所有输入均对应唯一评分记录。 |
| DATA-02 | 受限全文检索 | 独立数据库，只导入 manifest 中的 PDF。 | 对全文任务按题目限定的论文检索前 36 段；用版本与页码对照参考页。 | 每个全文任务有结果，所有命中均在允许范围；报告各题型参考页覆盖率。 |
| DATA-03 | 缺失文件与限定段落 | 三个缺文件题的指定文件放在不可读路径，三个限定段落题仅提供输入段落。 | 尝试读取缺失文件；限定段落题仅开放给定文本并关闭检索工具。 | 缺文件读入失败，记录 blocked，语义标签为空；限定段落判定不访问全文。 |

## 论文测试流程

1. 固定代码提交与数据树，验证论文身份、页数和引句。只将 PDF 导入临时 SQLite 工作区，推理端读取 `task_inputs.jsonl`。
2. 每轮对同一批题分别执行固定检索、Agent、Agent 加 Wiki 线索。三组使用同一模型、题目和输出格式，各跑两轮。固定检索取 BM25 前 36 段；Wiki 使用允许论文首页生成的静态阅读线索，引用仍须回到已读段落。限定段落题三组都只读输入，缺文件题只检查一次读入阻塞。
3. 单独走桌面 RPC，逐题建临时主题、导入 PDF、准备和启动任务、轮询终态，再用 `evidence.open` 回读锚点。覆盖 18 道全文问答和 3 道比较。端到端完成率包含服务错误。
4. 冻结输出后才由评分端读取 `cases.jsonl`。记录题号、模式、轮次、答案、证据、耗时与失败原因。先计算每轮分数，再并列两轮结果。模型判分可复算，独立人工仲裁另记。

| 任务 | 数量 | 输入和判定 |
|---|---:|---|
| 阅读问答 | 18 | 对照参考答案和证据，核对论文版本、页码及原文；页码按 PDF 文件顺序从 1 开始。 |
| 引用匹配 | 18 | 分列已判支持与尚未评判的候选。未评判命中单列，不能当作负例；补齐标注前不报告最终精确率或召回率。 |
| 引用回查 | 42 | 18 支持、18 矛盾、3 证据未确立、3 全文不可用。逐个子论述核对；未确立只限给定段落。不可用样例的语义标签为空，单独检查是否报告阻塞。 |
| 文献发现 | 3 | 在各题允许的候选集中用初步相关性等级核对排序，记录 k 和每题结果。最终排名指标待相关性复核。 |
| 论文比较 | 3 | 对照方法、任务和实验条件核查比较结论及证据。例：SPECTER 与 SciBERT 可在共同的 SciDocs 实验中比较，两者各自原任务的得分不能直接相减。 |

当前标注状态为 `assistant_source_checked`，尚未完成人工独立标注与仲裁。支持和矛盾变体可能共享同一论文事实；保留对应关系，试评结果不作为独立自然样本上的最终成绩。

## 指标与分母

| 指标 | 计算方法 |
|---|---|
| 参考页覆盖率@36 | 各题命中的不同参考（论文、页）数 ÷ 该题不同参考页数，再按题平均。只统计开放全文检索的题。 |
| 问答及比较正确率 | 回答涵盖所问核心要点并符合参考的题数 ÷ 全部该类题数。另判已验证的引句是否共同支撑答案的实质论述；空答案计失败。 |
| 引句可核验率 | 已读范围内可恢复原文的引句条数 ÷ 所有提交的引句条数。另报无有效引用的题数，避免漏引提高比例。 |
| 引用回查准确率、误支持率 | 对 39 道可判定题逐题核对标签。本批每题的原子标签一致。误支持率分母为 18 道矛盾题和 3 道限定段落题；分子为其中被判 supported 的题数。 |
| 已知支持来源覆盖、发现 Recall@3 | 引用匹配按题计算找回的已知正例占比，未判候选另计；发现按题计算排序前三的不同相关论文数 ÷ 该题标注相关论文数，再取平均。 |
| 运行与成本 | 报告任务终态、每轮每题耗时中位数、工具调用数及供应商返回的输入加输出 token。两轮共用题目，独立题数不翻倍。 |
